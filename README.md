# juju.lol reborn

juju brought back for da hood copies and more games. free, open source, made by #pepiguzman. original juju by xander.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/pepiguzman/juju-lol-reborn/main/dist/loader.lua"))()
```

## games

- hood customs
- zhd
- da strike (gun-ffa)
- da bot aim trainer
- da uphill
- da downhill
- dah aim trainer
- the arab hood
- nyan flame trainer
- murderers vs sheriffs duels
- hypershot
anything else loads the universal build, it tries to find the remote and bodyeffects on its own.

## files

- `dist/` what the loader downloads
- `copies/` one file per game + `index.json` with the place ids

configs, themes and sounds go in `workspace/juju.lol reborn/`.

found a bug or want a game added? DM pepiguzman on discord.
